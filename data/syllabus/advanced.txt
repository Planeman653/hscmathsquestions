## 11.1 Working with functions
### 11.1.1 Algebraic techniques
11.1.1.1 Use index laws to simplify expressions and solve problems involving positive, negative, zero or fractional indices
11.1.1.2 Expand, factorise and simplify algebraic expressions
11.1.1.3 Simplify expressions involving algebraic fractions
11.1.1.4 Expand and simplify expressions involving surds
11.1.1.5 Identify the conjugate of $\sqrt{a} \pm \sqrt{b}$, and rationalise the denominators of expressions of the form $\frac{a}{\sqrt{b} \pm \sqrt{c}}$ and $\frac{\sqrt{a} \pm \sqrt{d}}{\sqrt{b} \pm \sqrt{c}}$, where $a$, $b$, $c$ and $d$ are positive rational numbers
11.1.1.6 Solve quadratic equations $ax^{2} + bx + c = 0$ by factorisation, completing the square and using the quadratic formula $x = \frac{- b \pm \sqrt{b^{2} - 4ac}}{2a}$ where $a$, $b$ and $c$ are real numbers and $a \neq 0$
11.1.1.7 Define the discriminant as $\Delta = b^{2} - 4ac$ and use it to solve problems involving the number of real roots of a quadratic equation and determine the conditions for roots to be equal, distinct, real or rational
### 11.1.2 Introduction to functions and relations
11.1.2.1 Describe a relation between two sets as an association between the elements of one set and the elements of the other set
11.1.2.2 Define a real function $f$ of a real variable $x$ as a relation where each element $x$ of a given set is associated with exactly one element $y$ of the second set
11.1.2.3 Recognise that a relation is a rule which can be represented by an algebraic formula, a table of values, a set of ordered pairs $(x,y)$ or a graph
11.1.2.4 Use the notation $f(x)$ to identify the unique value of $y$ associated with $x$ when working with functions, and refer to it as the value of $f$ at $x$
11.1.2.5 Refer to $x$ in a function $y = f(x)$ as the independent variable of the function, and refer to $y$ as the dependent variable
11.1.2.6 Substitute numeric and algebraic expressions into the formulas of functions
11.1.2.7 Apply the vertical line test on the graph of a relation to determine whether it represents a function
11.1.2.8 Define the domain of a function $f$ as the set of real numbers on which $f$ is defined
11.1.2.9 Define the range of a function $f$ as the set of values of $f(x)$ obtained as $x$ varies over the domain of $f$
11.1.2.10 Refer to a value in the domain of a function at which the function is 0 as a zero of the function
11.1.2.11 Recognise that the $x$-intercepts of the graph of $y = f(x)$ are its zeroes, the solutions of $f(x) = 0$, and that the $y$-intercept is $f(0)$

11.1.3.4 Determine the equation of a straight line passing through two points $\left( x_{1},y_{1} \right)$ and $\left( x_{2},y_{2} \right)$ by calculating its gradient $m$ using the formula $m = \frac{y_{2\ } - \ y_{1}}{x_{2\ } - \ x_{1}}$
11.1.3.5 Determine the $x$-intercept and $y$-intercept of a straight line given its equation
11.1.3.6 Choose and apply appropriate techniques to graph a straight line given its equation
11.1.3.7 Find the equation of a line that is parallel or perpendicular to a given line
11.1.3.8 Solve linear inequalities and graph the solution on a number line

## 11.4 Introduction to differentiation
### 11.4.1 Estimating change
11.4.1.1 Define the average rate of change of $y$ with respect to $x$ for a function $y = f(x)$ over the domain $\lbrack a,b\rbrack$ as $\frac{\Delta y}{\Delta x} = \frac{\text{change in }y}{\text{change in }x}$, that is $\frac{\Delta y}{\Delta x} = \frac{f(b) - f(a)}{b - a}$, and recognise $\frac{f(b) - f(a)}{b - a}$ as the gradient of the secant through $\left( a,f(a) \right)$ and $\left( b,f(b) \right)$ on the graph of $y = f(x)$
11.4.1.2 Recognise speed as a rate of change of distance with respect to time
11.4.1.3 Use the definition for average rate of change to determine the average speed of an object from a given distance–time graph
11.4.1.4 Describe the difference between the average speed of an object and its instantaneous speed
11.4.1.5 Determine that the instantaneous speed of an object at time $t$ can be approximated by the average speed between its position at time $t$ and its position some time later, and explain how this approximation can be improved
11.4.1.6 Relate the instantaneous speed of an object to the gradient of the tangent at that point on its distance–time graph
11.4.1.7 Estimate the instantaneous speed of an object from its distance–time graph
11.4.1.8 Recognise when modelling with a linear function that its gradient is the rate of change and determine the rate of change for linear functions in practical situations
11.4.1.9 Recognise when modelling with a non-linear function that the rate of change is not constant and is represented by the gradient of the tangent to the curve at each point on the curve
11.4.1.10 Estimate the instantaneous rate of change of a non-linear function at a given point from a given graph of a practical situation
### 11.4.2 The derivative
11.4.2.1 Examine the gradient of a curve at a point on the curve using graphing applications
11.4.2.2 Approximate the gradient of a curve $f(x) = x^{n}$ at a point $P\left( c,f(c) \right)$ by considering the gradient of the secant through $P$ and $Q\left( c + h,f(c + h) \right)$ as the magnitude of $h$ approaches zero, using graphing applications or a spreadsheet
11.4.2.3 Infer that $nx^{n - 1}$ is the gradient of $f(x) = x^{n}$ and verify the result using graphing applications
11.4.2.4 Define $f'(x)$, for any function $f(x)$ and any value $x$, to be the gradient of the tangent to the curve $y = f(x)$ at the point $P\left( x,f(x) \right)$ if the tangent exists and is not vertical
11.4.2.5 Refer to $f'(x)$ as the derivative of $f(x)$ or the gradient, or derived, function of $f(x)$
11.4.2.6 Define differentiation as the process of finding the derivative of a function
11.4.2.7 Find derivatives of constant and linear functions
11.4.2.8 Define the derivative of the function $f(x)$ from first principles, as the limiting value of the gradient of the secant $\frac{f(x + h) - f(x)}{h}$ as $h$ approaches zero, when this limiting value exists, and use the notation $f'(x) = \underset{h \rightarrow 0}{lim}\frac{f(x + h) - f(x)}{h}$
11.4.2.9 Use first principles to find the derivative of quadratic functions
### 11.4.3 Calculations with the derivative
11.4.3.1 Use the notation $\frac{dy}{dx}$ and $y'$ for the derivative of $y$ when $y$ is a function of $x$
11.4.3.2 Use the notation $\frac{d}{dx}\left( f(x) \right)$ and $f'(x)$ for the derivative of a function $f(x)$
11.4.3.3 Use the formula $\frac{d}{dx}(x^{n}) = nx^{n - 1}$ for all real values of $n$
11.4.3.4 Apply the fact that the derivative of a sum is the sum of the derivatives: $\frac{d}{dx}\left( f(x) + g(x) \right) = f'(x) + g'(x)$, and the derivative of a multiple of a function is the multiple of its derivative: $\frac{d}{dx}(k \cdot f(x)) = k \cdot f'(x)$
11.4.3.5 Use the rules for differentiation to find equations of tangents and normals to a curve at points on the curve
11.4.3.6 Find points on a curve where the tangent or normal has a given gradient
11.4.3.7 Examine and use the relationship between the angle of inclination of a line or tangent to a curve, $\theta,$ with the positive $x$-axis, and the gradient, $m$, of that line or tangent, and establish that $\tan\theta = m$
11.4.3.8 Apply the product rule: if $y = uv$, where $u$ and $v$ are both differentiable functions of $x$, then $\frac{dy}{dx} = u\frac{dv}{dx} + v\frac{du}{dx}$ or if $h(x) = f(x)g(x)$ for differentiable functions $f(x)$ and $g(x)$ then $h'(x) = f(x)g'(x) + f'(x)g(x)$
11.4.3.9 Apply the quotient rule: if $y = \frac{u}{v}$, where $u$ and $v$ are both functions of $x,$ then $\frac{dy}{dx} = \frac{v\frac{du}{dx} - u\frac{dv}{dx}}{v^{2}}$ or if $h(x) = \frac{f(x)}{g(x)}$ then $h'(x) = \frac{g(x)f^{'}(x) - f(x)g^{'}(x)}{\lbrack{g(x)\rbrack}^{2}}$
11.4.3.10 Apply the chain rule: if$\ y$ is a differentiable function of $u$, and $u$ is a differentiable function of $x$, then $\frac{dy}{dx}\ = \ \frac{dy}{du} \times \frac{du}{dx}$ or if $h(x) = f\left( g(x) \right)$ for differentiable functions $f(x)$ and $g(x)$ then $h'(x) = f'\left( g(x) \right)g'(x)$
11.4.3.11 Identify and apply the product, quotient or chain rule, or a combination of the rules, as appropriate to differentiate a given function
### 11.4.4 Graphical applications of the derivative
11.4.4.1 Interpret $f(x)$ as increasing at $x = c$ when $f'(c) > 0$ and decreasing at $x = c$ when $f'(c) < 0$

## 11.7 Probability and data
### 11.7.1 Sets and set notation
11.7.1.1 Define a set as a collection of objects, called the elements of the set, and represent a set using notation such as $\left\{ 2,3,5,7 \right\}$ and $\{ 0,2,4,6,\ldots\}$

11.7.1.5 Define $A$ to be a subset of $B$ if all the elements of $A$ are elements of $B$
11.7.1.6 Define the intersection $A \cap B$ of sets $A$ and $B$ to be the set of elements that are in $A$ and in $B$
11.7.1.7 Define the union $A \cup B$ of sets $A$ and $B$ to be the set of elements that are in $A$ or in $B$

### 11.7.2 Probability
11.7.2.1 Define an experiment or a trial to be any procedure that can be infinitely repeated and has a well-defined set of possible outcomes known as the sample space, denoted $S$
11.7.2.2 Identify an event $A$ as a subset $A$ of the sample space $S$
11.7.2.3 Define the probability of each outcome to be $\frac{1}{|S|}$ when all the outcomes are equally likely and the probability of the event $A$ to be $P(A) = \frac{|A|}{|S|}$
11.7.2.4 Interpret the notation $\overline{A}$ to be the event '$A$ does not occur', interpret $A \cap B$ to be the event '$A$ and $B$ both occur', and interpret $A \cup B$ to be the event '$A$ or $B$ occurs'
11.7.2.5 Use Venn diagrams to represent the relationship between events within the same sample space, including mutually exclusive events, that is, events that as subsets of the sample space are disjoint
11.7.2.6 Establish and use the rules $P\left( \overline{A} \right) = 1 - P(A)$ and $P(A \cup B) = P(A) + P(B) - P(A \cap B)$
11.7.2.7 Use arrays and tree diagrams to determine the outcomes and probabilities for multistage events
### 11.7.3 Conditional probability
11.7.3.1 Define conditional probability as the probability that an event $A$ occurs given that another event $B$ has already occurred, and use the notation $P(A\left| B) \right.
11.7.3.2 Examine conditional probability by restricting the sample space and event spaces in a Venn diagram, using a two-way table, a tree diagram and other arrays
11.7.3.3 Establish that $P\left( A|B \right) = \frac{|A \cap B|}{|B|}$ when all outcomes are equally likely by restricting the sample space and event space, and hence $P\left( A|B \right) = \frac{P(A \cap B)}{P(B)}$, provided $|B| \neq 0$
11.7.3.4 Use the formulas for $P(A|B)$ to solve practical problems involving conditional probability
11.7.3.5 Define two events to be independent if the occurrence of one event does not affect the probability that the other event occurs
11.7.3.6 Explain that two events $A$ and $B$ are independent means $P\left( A \middle| B \right) = P(A)$ and $P\left( B \middle| A \right) = P(B)$, and show algebraically that if one of these formulas is true, then the other is also true
11.7.3.7 Use the formula $P\left( A|B \right) = \frac{P(A \cap B)}{P(B)}$, and the test $P\left( A \middle| B \right) = P(A)$ for independence to prove that if two events are independent, then $P(A \cap B) = P(A) \times P(B)$, and to prove conversely that if $P(A \cap B) = P(A) \times P(B)$, then $A$ and $B$ are independent
11.7.3.8 Solve practical problems involving independent events

12.2.2.1 Define a sequence $a_{n}$ to be an arithmetic sequence, or arithmetic progression (AP), if every difference $a_{n} - a_{n - 1}$ of successive terms is the same where $n \geq 2$, that is $a_{n} - a_{n - 1} = d$ for some constant $d$ called the common difference

### 12.2.3 Geometric sequences and series
12.2.3.1 Define a sequence $a_{n}$ to be a geometric sequence, or geometric progression (GP), if every ratio $\frac{a_{n}}{a_{n - 1}}$ of successive terms is the same where $n \geq 2$, that is $a_{n} = ra_{n - 1}$ for some non-zero real number $r$ called the common ratio

### 12.6.2 Continuous random variables
12.6.2.1 Estimate the probability that a continuous random variable falls in some interval using relative frequencies and histograms obtained from data
12.6.2.2 Recognise that the probability of a particular value for a continuous random variable is 0 and hence that $P(a < X < b) = P(a \leq X < b) = P(a < X \leq b) = P(a \leq X \leq b)$ since $P(X = a) = P(X = b) = 0$ when $X$ is a continuous random variable
12.6.2.3 Define the cumulative distribution function (CDF), $F(x)$, as the probability of a random variable, $X$, having values less than or equal to $x$, so $F(x) = P(X \leq x)$ and $P(a \leq x \leq b) = F(b) - F(a)$

12.6.2.5 Define a probability density function (PDF), $f(x)$, for a random variable $X$ with cumulative distribution function $F(x)$ as $f(x) = F'(x)$ and recognise that $P(a < X < b) = \int_{a}^{b}{f(x)}dx$
12.6.2.6 Recognise the properties of a probability density function: $f(x) \geq 0$ for all $x$ in the domain of $f(x),$ and $\int_{a}^{b}{f{(x})dx} = 1$ if the domain of $f(x)$ is $\lbrack a,b\rbrack$, or $\int_{- \infty}^{\infty}{f{(x})dx} = 1$ if the domain of $f(x)$ is all real $x$
