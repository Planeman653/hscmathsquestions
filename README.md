# HSC Maths Question Bank

Static site (GitHub Pages) that lists HSC Mathematics Advanced, Extension 1 and Extension 2 trial-paper
questions sorted by the NESA 11–12 (2024) syllabus — topic, subtopic and dot point — with difficulty
ratings, worked solutions and a PDF builder.

- `index.html`, `advanced.html`, `extension1.html`, `extension2.html` — pages (course pages generated by `scripts/make_pages.py`)
- `assets/` — `app.js`, `style.css`, cropped diagrams in `assets/img/<paper-id>/`
- `data/syllabus/` — parsed syllabuses (`scripts/parse_syllabus.py`), `.txt` listings for tagging
- `data/papers/<course>/<paper-id>.json` — one file per indexed paper (source of truth)
- `data/build/` — generated by `scripts/build.py`; what the site loads
- `data/ledger.json` — THSC papers already indexed or skipped
- `INDEXING.md` — the daily indexing procedure

Source papers: THSC Online (thsconline.github.io). Content not in the 2024 syllabus is dropped.
